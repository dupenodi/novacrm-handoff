# @novacrm/ui

The "Signal" design system, copied as-is from resumama (`apps/web/src/components/{theme,agent,domain}`).
Only import paths were rewritten (`@/components/theme` → `../theme`).

- `@novacrm/ui` — tokens, primitives (Button, Card, Chip, DataTable, Modal, …) and `ThemeProvider`
- `@novacrm/ui/agent` — agent-run surfaces (AgentRun, ToolCall, PlanPanel, FailureCard, …)
- `@novacrm/ui/domain` — composite cards (PageHeader, StatCard, ActivityFeed, …)

See `docs/design-system.md` for the component inventory and action-placement rules.
